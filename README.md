# Household Assistant OAuth information site

Static, public-facing informational pages for a private, non-commercial Google OAuth integration. No assistant application is hosted here.

## Contents
- `index.html`: application homepage
- `privacy.html`: Google data use and privacy description
- `terms.html`: usage terms
- `assets/`: static stylesheet and illustration

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save. The site works at the default `github.io` path and under a verified custom domain.

## Before going live
- Review privacy claims, especially AI-provider data handling, retention and sharing.
- Compare disclosed use against actual OAuth scopes and real workflows.
- For Google OAuth verification, use a custom domain you control and verify domain ownership in Google Search Console.
- Ensure public branding and links exactly match Google Auth Platform.
- Do not commit credentials, internal hostnames, access tokens, IP addresses or personal identifying data.

This repository is public. GitHub Pages does not host or connect to the private assistant.
